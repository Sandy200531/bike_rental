Bike Rental Demand Prediction
A simple machine learning project to predict bike rental demand using Python.
Requirements
•Python 3.8+
•NumPy
•Pandas
•Matplotlib
•Seaborn
•Scikit-learn

Install libraries:
pip install -r requirements.txt
Project Files
bike_rental_prediction.py
requirements.txt
data/
plots/
README.md

How to Run
Run the following command:
python bike_rental_prediction.py
The program will:
1.Create/load the dataset
2.Clean the data
3.Perform EDA
4.Create new features
5.Train ML models
6.Evaluate the models
7.Save results and plots

Models Used
•Linear Regression
•Random Forest
•Gradient Boosting

Evaluation
•MAE
•RMSE
•R² Score

Features
•Temperature
•Humidity
•Windspeed
•Hour
•Season
•Weather
•Working Day
•Rush Hour

Output
The project generates:
•Dataset
•Model results
•EDA plots
•Prediction plots
•Feature importance plot

Objective
To analyze bike rental patterns and predict bike rental demand using machine learning.
